## 项目基本参数
- 项目名称：DuckDB数据库从入门到进阶
- 版本基线：DuckDB v1.5.5（官方文档 docs/current 已完整研读）
- 文档类型：中文技术教程/书籍（入门到进阶）
- 目标读者：具备基础计算机操作能力、了解数据库概念的初学者；进阶部分面向真实数据分析与工程场景的开发者
- 写作语言：简体中文，严谨学术写作风格，自然流畅，避免模板化与明显 AI 痕迹
- 全书结构：19 章 / 7 大部分（基础入门 / 数据工程 / 客户端与生态集成 / 扩展机制 / 性能与运维 / 原理剖析 / 实战与总结）
- 关键事实（贯穿全书须一致）：
  - DuckDB 是进程内（in-process）分析型（OLAP）数据库，无独立服务进程，单文件数据库（.duckdb/.db/.ddb）
  - 列式存储 + 向量化执行（DataChunk/Vector，STANDARD_VECTOR_SIZE=2048）
  - MVCC 快照隔离；单事务只能写入一个 attached 数据库；写写冲突乐观失败需重试
  - 扩展二进制严格绑定具体 DuckDB 版本与平台（升级须重装匹配版本）
  - 主客户端：CLI、Python；SQL 语法各端通用
  - 默认 memory_limit=物理内存 80%；threads=核数；压缩持久库常快于未压缩内存表
  - 版本事实：GEOMETRY v1.5 成内置类型；VARIANT 支持 Parquet shredding；Quack 远程协议 v1.5.3 beta；DuckLake 1.0 于 2026-04 发布；lambda 单箭头 v1.5 末班车、v2.0 默认禁用
