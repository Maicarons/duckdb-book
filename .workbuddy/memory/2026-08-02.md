### GitHub 部署关键坑（重要）
- `gh` OAuth token **缺 `workflow` scope**，无法 push 含 `.github/workflows/*.yml` 的提交（remote rejected）。
- 因此改用 **「从分支部署」**：构建产物推到 `gh-pages` 分支，Pages 源设为该分支 `/`；`gh api POST /repos/.../pages` 报告显示 `build_type=legacy`、`source.branch=gh-pages`、`status=built`。
- git push 卡死（非代理问题）：因未用 gh token 认证，Git 走系统 credential manager 弹密码且终端禁用提示 → 改为先 `gh auth setup-git` 再 push 即正常。
- 可启用的 Actions 工作流保留在仓库根 `deploy-github-pages.yml`（故意不放进 `.github/workflows/` 以免阻塞 push）；README 已写激活步骤。
